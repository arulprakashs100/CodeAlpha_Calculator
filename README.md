# 🧮 CodeAlpha Calculator

A modern and responsive **Calculator** developed using **HTML, CSS, and JavaScript** as part of the **CodeAlpha Frontend Development Internship**.

This project features a clean and interactive user interface with smooth animations, keyboard support, calculation history, and a responsive design to provide an excellent user experience.

---

## 🚀 Features

- 🧮 Basic Arithmetic Operations (+, −, ×, ÷)
- ⌨️ Keyboard Support
- 📝 Calculation History
- 🗑️ AC (Clear All) & DEL (Delete)
- 🌙 Dark/Light Mode
- ⚡ Real-Time Display Updates
- ✨ Smooth Animations
- 📱 Fully Responsive Design
- ♿ Accessibility-Friendly
- 💻 Cross-Browser Compatible

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
